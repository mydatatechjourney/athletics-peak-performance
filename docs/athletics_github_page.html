Peak Performance in Elite Athletics

Exploring the relationship between athlete age and performance across the 100 metres, Marathon, Long Jump and Shot Put, with men's and women's events analysed separately.

Research Question

The project focuses on whether age is related to elite athletic performance and whether the pattern differs by event and gender.

At what age do athletes reach peak performance, and does this differ by event and gender?

Project Overview

I analysed four athletics events: 100 metres, Marathon, Long Jump and Shot Put. Men and women were analysed separately because the relationship between age and performance may not be the same across every discipline or gender.

The analysis covers the main stages of a data science project: data preparation, exploratory data analysis, correlation analysis, linear regression and second-degree polynomial regression.

Dataset

The project uses the World Athletics All-Time Rankings dataset available on Kaggle. The original dataset contains historical athletics performances across many events and competition categories.

For this project, I kept the variables needed to identify the athlete, event, gender, age and performance. The analysis was then restricted to senior outdoor men's and women's competitions and the four selected events.

Data Preparation

The original data needed to be cleaned and transformed before it could be used for regression modelling. I kept the process step-by-step so that each decision could be checked and explained.

Filtering

The data was restricted to the 100m, Marathon, Long Jump and Shot Put, using Outdoor Senior - Men and Outdoor Senior - Women.

Missing age

Where age was missing, I used date of birth and competition date to calculate it where possible. Records were removed when age could not be recovered.

Performance conversion

Running times and field-event distances were converted into numeric performance values. Marathon times were converted into total seconds.

Personal best selection

One personal-best observation was retained for each athlete, event and gender. Lower values were selected for timed events and higher values for distance events.

Outlier treatment

Potential outliers in age and performance were identified separately within each event and gender using the 1.5 × IQR rule.

Final checks

Missing values and duplicate athlete/event combinations were checked again before exploratory analysis and modelling.

Exploratory Data Analysis

I used descriptive statistics and visualisations to understand the age distributions before modelling. Mean, median, standard deviation, minimum, maximum and skewness were calculated separately for each event and gender.

Marathon athletes were older on average than athletes in the 100m and Long Jump groups. Across all eight groups, skewness was positive but relatively small, showing a slight tendency towards a longer tail at older ages.

Linear Regression

Linear regression was used first to investigate whether performance had a simple straight-line relationship with age. Pearson's correlation coefficient was also calculated for each event and gender to show the direction and strength of the linear association.

Important: a linear regression model cannot calculate an internal peak age because a straight line has no turning point.

The correlations shown in the plots were generally weak. For example, Men's 100m had a Pearson correlation of -0.135, Women's 100m -0.118, Men's Long Jump 0.075 and Women's Long Jump 0.115. The Marathon correlations were also close to zero.

Polynomial Regression

I then used second-degree polynomial regression. Adding an age-squared term allows the fitted relationship to curve and therefore creates the possibility of a turning point.

A turning point was only interpreted as a performance peak when it represented the best predicted performance for the event. For the 100m and Marathon this requires a minimum time. For Long Jump and Shot Put this requires a maximum distance.

A mathematical turning point does not automatically mean that the model is strong. The R-squared values were generally close to zero or negative, so the estimated peak ages need to be interpreted cautiously.

Key Findings

Age alone explains little variation

The test-set R-squared values were low across the linear and polynomial models. This means age on its own does not explain much of the difference in performance between elite athletes.

100m produced valid polynomial peaks

The polynomial models estimated peak ages of approximately 29.71 years for men and 28.50 years for women.

Long Jump peaks differed by gender

The estimated polynomial turning points were approximately 25.62 years for men and 30.16 years for women.

Marathon did not produce a valid peak

The Marathon turning points were maxima in predicted time, rather than the minimum time needed to represent best performance.

Limitations

  • Age is the main predictor. Athletic performance is influenced by many other factors that are not included in these models.
  • The dataset contains elite performances. The results should not be generalised to all athletes.
  • Personal-best selection changes the question slightly. Each athlete contributes one selected personal best rather than a full career performance history.
  • Outlier removal is a modelling choice. The IQR method helps reduce extreme observations, but an outlier is not automatically an incorrect record.
  • Low R-squared values limit interpretation. A valid polynomial turning point can exist even where the model explains very little of the variation in performance.

Conclusion

This project found that age has some relationship with elite athletics performance, but age alone is not a strong predictor across the selected events. The large amount of variation between athletes of similar ages is reflected in the generally low R-squared values.

Polynomial regression was useful for investigating whether the age-performance relationship could contain a turning point. It produced plausible peak-age estimates for some event and gender groups, including the 100m and Long Jump. However, the Marathon models did not produce the type of turning point needed to represent best performance.

Main takeaway: the estimated peak ages are useful as model-based indicators, but they should not be treated as exact biological peak ages. A future version of the project could include additional explanatory variables, such as wind conditions where relevant, to test whether model performance improves.
