Peak Performance in Elite Athletics

A data science project exploring the relationship between athlete age and performance across the 100m, Marathon, Long Jump and Shot Put.

GitHub Repository Jupyter Notebook

Research Question

At what age do athletes reach peak performance, and does this differ by event and gender?

Project Overview

This project investigates the relationship between age and performance in elite athletics. I analysed four events:

  • 100 metres
  • Marathon
  • Long Jump
  • Shot Put

Men's and women's performances were analysed separately. The project includes data cleaning, exploratory data analysis, Pearson correlation, linear regression and second-degree polynomial regression.

Dataset

The project uses the World Athletics All-Time Rankings dataset available on Kaggle.

View dataset on Kaggle

Data Preparation

The main preprocessing steps included:

  • Filtering to the four selected events.
  • Separating men's and women's competitions.
  • Removing duplicate records.
  • Calculating missing ages where date of birth and competition date were available.
  • Removing records where age could not be determined.
  • Converting performances into numeric values.
  • Selecting each athlete's personal-best performance.
  • Identifying and removing potential outliers using the IQR method.

Exploratory Data Analysis

I explored the distribution of age for each event and gender using descriptive statistics, histograms and box plots. Skewness was also calculated to understand the shape of each age distribution.

Linear Regression

Linear regression was used to investigate whether there was a simple linear relationship between age and performance. Pearson's correlation coefficient was also calculated to show the direction and strength of the relationship.

The correlations were generally weak, suggesting that age alone has a limited linear relationship with performance.

Polynomial Regression

Second-degree polynomial regression was used to investigate whether the relationship between age and performance was curved. This also allowed a turning point to be calculated.

For timed events, a valid performance peak needs to represent a minimum predicted time. For distance events, it needs to represent a maximum predicted distance.

Key Findings

100m: the polynomial models estimated peak ages of approximately 29.71 years for men and 28.50 years for women.
Long Jump: the estimated polynomial peak ages were approximately 25.62 years for men and 30.16 years for women.
Marathon: turning points were identified, but they represented maximum predicted times rather than minimum times and were therefore not treated as valid performance peaks.

Overall, the R-squared values were low. This suggests that age alone explains only a small amount of the variation in elite athletic performance.

Limitations

  • Age was used as the main predictor.
  • Other factors affecting performance were not included.
  • The dataset represents elite athletes rather than all athletes.
  • Each athlete's selected personal best was used rather than their full career history.
  • Low R-squared values mean the estimated turning points should be interpreted cautiously.

Conclusion

The analysis shows that the relationship between age and elite athletic performance differs across events and genders. Polynomial regression was able to identify turning points for several groups, but the low R-squared values show that age is only one part of the explanation for performance.

The estimated peak ages should therefore be treated as model-based estimates rather than exact biological peak ages. Future analysis could include additional variables, such as wind conditions where relevant, to investigate whether the models can be improved.
