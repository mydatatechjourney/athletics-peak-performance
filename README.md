# Athletics Peak Performance Analysis

## Project Overview

This data science project investigates the relationship between
age and performance in elite athletics.

### Research Question

**At what age do athletes reach peak performance, and does this
differ by event and gender?**

The analysis focuses on four events:

- 100 metres
- Marathon
- Long Jump
- Shot Put

Men's and women's performances are analysed separately.

## Methods

The project includes:

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Descriptive statistics
- Pearson correlation
- Linear regression
- Polynomial regression
- Polynomial turning-point analysis
